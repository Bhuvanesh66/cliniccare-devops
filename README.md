# ClinicCare

ClinicCare is a clinic appointment-booking system for a front desk: register
patients, manage doctors, book appointments without double-booking anyone,
and move each visit through check-in to completion.

This repository is the DevOps final capstone: the application plus everything
that takes it from a laptop to a monitored Kubernetes cluster on AWS.

> Full documentation is written as the project progresses.

## Run it locally

```bash
docker compose up --build
```

- UI: http://localhost:3000
- API docs: http://localhost:8000/docs
