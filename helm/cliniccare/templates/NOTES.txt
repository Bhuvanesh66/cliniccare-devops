Application URL (the load balancer can take 2-3 minutes to become active):
  kubectl -n {{ .Release.Namespace }} get ingress {{ include "cliniccare.fullname" . }} \
    -o jsonpath='http://{.status.loadBalancer.ingress[0].hostname}{"\n"}'
{{- else }}

Open the UI with a port-forward:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "cliniccare.fullname" . }}-frontend 8080:80
  then browse to http://localhost:8080
{{- end }}

Check the release from inside the cluster:
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }} --logs
